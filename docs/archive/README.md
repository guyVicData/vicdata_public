# docs/archive

Round-specific working artifacts: briefs, Claude Code prompts, build and verification
reports, handoff notes, superseded specs and drafts. Everything here instructed or
recorded ONE build round that has since shipped. Kept for history, not for reference.

**Nothing in here should be read as a current description of how the system works.**
For that, see the standing docs at the top level of `docs/` -- the roadmap, the three
`vicdata_briefing_*_what_is_measured_*` docs, and the living lists.

**Convention going forward:** when a round's brief/prompt/build-report is confirmed
shipped, `git mv` that round's own files in here as the last step of that round's own
commit, rather than letting the pile rebuild.

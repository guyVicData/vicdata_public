Consistency

One vocabulary: the walk teaches the dashboard

Each walk screen is a dashboard panel, enlarged and explained. Whatever a teacher sees in a walk, they meet again on the dashboard in the same place, with the same icon, colour and words. The walk says in full what the dashboard says in shorthand: a label beside each rail icon, a question beside each column name, a key on every chart.

The same three things everywhere: the home button, the walk's top bar, the walk's panel header, the dashboard's column header and the mini-map. Icons are the dashboard's own (COLUMN_ICON_PATHS), tinted in the phase colour.

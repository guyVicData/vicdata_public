See the prompt, Part 2.
3. **A first draft of the comparator (school) chooser.** Guy asked, twice, that this reuse the real subject-picker's conventions (`CategorySubjectPicker.tsx` — tabs, coloured categories, removable chips) rather than a new pattern, which is what the wireframe (`https://claude.ai/artifact/8SLvLpLqFUHeaDoiv5yR2v`, Version 2) was rebuilt to do. See the prompt, Part 3.

See the prompt, Part 4.

Parts 3 and 4 are explicitly first drafts, in the same spirit as the Trend/% Change round: get the real mechanism working end to end, then react to it live rather than iterating blind. Part 1 and 2 are not drafts — the bug fix is a bug fix, and the accordion is a direct, unambiguous instruction.
